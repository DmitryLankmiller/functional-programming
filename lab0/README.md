## Clojure

Для выполнения лабораторных работ я выбрал язык программирования Clojure.

Такое решение я принял отталкиваясь от темы для лабораторной работы №4. Я хочу написать приложение, которое будет анализировать криптовалютные биржи с целью арбитражной тороговли.

Из предложенных языков я решил, что мне больше всего подходят Clojure и Erlang, так как для проекта придётся параллельно запрашивать котировки валютных пар с нескольких бирж.

- Прочитав сравнение этих двух языков и углубившись в поставленную цель, я понял, что для анализа данных на одной машине Clojure подходит лучше, чем Erlang.
- Также в Clojure больше библиотек для работы с вычислениями (Neanderthal, Incanter, core.matrix, clojure.spec).
- Приятным бонусом для меня было то, что Clojure работает на виртуальной машине Java (JVM) и, таким образом, имеет доступ к обширной экосистеме и библиотекам Java.
- Также мне очень понравился REPL в Clojure. Его наличие сильно ускоряет процесс разработки, очень удобно экспериментировать с вычислениями и преобразованиями данных.
